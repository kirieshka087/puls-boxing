# ПУЛЬС

Портфолио-концепт вымышленной школы профессионального бокса
Цены, имена, достижения, адрес и телефон демонстрационные

Откройте index.html в браузере или разместите файл в корне GitHub Pages
CSS, JavaScript, изображения и видео встроены в HTML
Сборка и установка зависимостей не нужны
Google Fonts загружаются при подключении к сети

- Второй удар из предоставленного ролика с молнией
- Исходный фрагмент от 2,72 до 5,05 секунды растянут до 9,6 секунды с нарастающим замедлением и финальной остановкой
- Звуковая дорожка удалена
- Чёрный прелоадер с логотипом и живой кардиограммой
- Центрированный первый экран и плавная кнопка с выбором тренировки
- Новый логотип, спортивная сумка, перчатки и шлем
- Чёрно-белые фотографии с плавным приближением
- Анимированный счётчик 11 лет
- Интерактивные пропуски с составом программы, выбором бокса и кикбоксинга
- Кастомные списки в форме, автоматический перенос направления и расчёт цены
- Белая неподвижная надпись ПУЛЬС с кардиограммой в подвале
- Поддержка клавиатуры и уменьшенной анимации

## Форма

Форма работает в демонстрационном режиме и ничего не отправляет
После корректного заполнения показывает уведомление об этом

Для настоящего клуба задайте CONFIG.leadEndpoint и замените демонстрационные контакты в HTML
Стоимость и программы находятся в объекте programs
Обработчик получает POST JSON с полями name, phone, direction, audience, plan и consent
Для другого домена необходимо разрешить CORS
Ответ HTTP 2xx должен означать принятую заявку

## Проверка

Проверены выбор направления, программы абонементов, отдельные цены для двух видов спорта, персональный кикбоксинг, проверка формы и демонстрационное заполнение
Проверены desktop и мобильные экраны 390 и 320 px
JavaScript проверен через node --check
